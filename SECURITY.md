# Security Policy

## Reporting a Vulnerability

We take the security and integrity of Proofly seriously. If you believe you have discovered a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### Responsible Disclosure Guidelines

- **Do NOT open a public GitHub issue** for suspected security vulnerabilities or leaks.
- Please report vulnerabilities privately via [GitHub Private Vulnerability Reporting](https://github.com/17rajsal/document-forgery-ai/security/advisories/new).
- Provide a detailed description of the vulnerability, including step-by-step reproduction steps or proof-of-concept payloads.
- Allow reasonable time for the maintainers to investigate and address the vulnerability before public disclosure.

### User Privacy & Document Safety

- **Never upload or attach real sensitive personal documents** (such as Aadhaar cards, passports, personal tax returns, or private bank statements) to public bug reports, issues, or pull requests.
- All testing and benchmark evaluation must use synthetic, generated, or publicly available dummy documents.
- Proofly is designed with privacy-first principles: files uploaded for analysis are processed in ephemeral containers and not retained as permanent public assets.
